## Fonctionnalités principales

### Générateur de Templates HTML5/CSS3

Choisis ton gabarit en fonction de tes besoins (nombre de zones, de colonnes, grille intégrée). Ton vœu est exaucé et ton template s'affiche devant tes yeux ébahis. Affiche ce dont tu as besoin (HTML, CSS ou résultat visuel), puis tu n'as plus qu'à récupérer le code source du template choisi. Tu peux même le modifier en direct si ça te fait plaisir !

Voici les types de gabarits disponibles :

- Structure HTML seule
- Une seule colonne, entête, contenu
- Sidebar, contenu fluide
- Entête, sidebar, contenu fluide
- Entête, sidebar, contenu fluide, footer
- Entête, double sidebar, contenu fluide, footer
- Entête, grille x3, footer
- Entête, grille x6, footer
- Entête et footer "Hero"
- Composition originale 1

### Prévisualisation et Export

- Visualisez le code HTML, CSS et le résultat directement dans le navigateur.
- Intégration avec CodePen pour voir et modifier les templates en direct (`data-slug-hash` mis à jour dynamiquement).
- Récupérez facilement le code source du template choisi.

### Qualité et Modernité

- Templates basés sur une structure HTML5 propre.
- Inclusion de la balise `meta name="viewport"` pour le Responsive Web Design.
- Utilisation de CSS3 Grid Layout pour les gabarits.
- Les textes par défaut sont remplis avec l'algorithme savant _Schnapsum®_.
